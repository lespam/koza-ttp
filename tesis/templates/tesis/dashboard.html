👋 {% translate "¡Bienvenido a la aplicación!" %}

{% blocktranslate trimmed %}Este sistema interactivo busca resolver de manera óptima la organización y logística de un calendario para una temporada completa de béisbol. Para lograrlo, implementamos una técnica de inteligencia artificial avanzada inspirada directamente en la evolución natural de las especies.{% endblocktranslate %} 🌿

{% blocktranslate trimmed %}La programación genética consiste en crear, evaluar y modificar soluciones de forma automática a partir de una población inicial de programas. Esto se logra ejecutando operaciones bioinspiradas como la selección natural, el cruzamiento y la mutación. En este entorno, cada programa generado se estructura internamente como un árbol de expresión que representa una solución potencial para nuestro calendario.{% endblocktranslate %}

{% blocktranslate trimmed %}El algoritmo evalúa continuamente cada árbol mediante un criterio estricto de calidad (función de aptitud o fitness) con la meta de heredar características clave y generar nuevos árboles cada vez más prometedores.{% endblocktranslate %} 📈 {% translate "¡Este proceso se repite en un bucle evolutivo hasta hallar la solución óptima y más eficiente!" %}

{% translate "3. Inicialización, ciclo evolutivo y convergencia" %}

📍 {% translate "Fase de ejecución en vivo:" %} {% blocktranslate trimmed %}El sistema genera una población inicial aleatoria y convierte cada propuesta en una estructura jerárquica de árbol (syntax tree). ¡Aquí es donde ocurre la magia computacional!{% endblocktranslate %} ✨
  1. {% translate "Visualización y muestreo:" %} {% translate "Se procesa la población inicial y se genera el renderizado de los árboles mediante el generador de sintaxis." %}
  2. {% translate "Evaluación de aptitud:" %} {% blocktranslate trimmed %}Se calcula el valor de fitness de cada individuo en base a la distancia acumulada en kilómetros y el cumplimiento normativo.{% endblocktranslate %}
  3. {% translate "Selección natural:" %} {% translate "Se escogen los mejores individuos de la ronda anterior para actuar como padres biológicos de la nueva generación." %}
  4. {% translate "Cruzamiento, mutación y herencia:" %} {% translate "Se crean nuevos individuos mezclando ramas de árboles destacados y aplicando mutaciones en nodos aleatorios." %}
  5. {% translate "Bucle iterativo:" %} {% translate "Se repiten secuencialmente los pasos de evaluación, selección y reproducción hasta completar el total de generaciones configuradas en la interfaz." %}
  6. {% translate "Resultados oficiales:" %} {% translate "El mejor individuo obtenido en la última iteración se valida y su estructura interna se almacena como el calendario definitivo del torneo de béisbol." %} 🏆🎉
